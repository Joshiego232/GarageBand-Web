# Plugin face artwork

Drop generated face artwork in this folder as PNG files named by the IDs below.
Use art-only faceplates: the app renders titles, labels, knobs, LEDs, and switches
as UI elements. Avoid baked-in text, logos, knobs, or hardware.

Pedalboard faces should use a portrait 230:296 aspect ratio. Audio plugin card
faces should use a landscape 3:2 aspect ratio. Artwork is not wired into the UI
yet; adding files here prepares the asset location but does not display them.
